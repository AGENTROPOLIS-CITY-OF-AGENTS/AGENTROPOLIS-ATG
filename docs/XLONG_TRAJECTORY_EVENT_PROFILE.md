# ATG / ATRALITH X-LONG trajectory profile (proposal)

Status: contract-only; NOT a ratified ATG primitive. See AGENTROPOLIS-UTILITY-GRID draft PR #50.

An agent-event edge in an extreme-long-horizon mission describes evidence lineage, not permission inheritance.
- Authority chain remains Identity → Mandate → Plan → Execute → Receipt → Audit.
- Bind tenant, mission, agent, envelope and task branch only after admission; reject cross-tenant edges.
- Child/spawn agents require independent passport, mandate, permissions, execution envelope and receipts.
- Retry, compaction, checkpoint and timeout links preserve origin and parent proof. Derived fingerprints do not prove authorization.
- Human review required for learning dataset promotion and all production model/tool/skill permissions.
- ATRALITH / ATG future extensions MAY encode semantic event typing and sub-agent lineage, but this document grants no new syntax, runtime status, or execution power.
- Do not persist hidden chain-of-thought, secrets, arbitrary raw user messages or private chats.

Acceptance: typed event schema map, independent evaluator evidence, tamper-evident receipt chain, review by ATG authority owner + AEGIS/54T.

No live ATG compiler/schema was modified.
