# ATG ELEMENTAL-5 | Draft v0.1 (TEST ONLY)

Status: proposed ATG domain profile, not an independent authority or deployed runtime.

## Purpose
Compose five bounded capability classes across AGENTROPOLIS, serving BOTH (1) governed district construction and its evidence-backed Digital Mirror in WORLD, and (2) Math54 Elemental Lab with chemistry, physics, math, and biology experiences. The names are metaphors, not chemical elements or independent autonomous authorities.

| Element | Capability | Inputs | Outputs | Boundary |
|---|---|---|---|---|
| AIR | PERCEIVE | approved references, observation scope | evidence manifest, requirements | read-only |
| EARTH | MATERIALIZE | approved design spec, asset refs | draft geometry, structures | isolated workspace |
| WATER | TRANSFORM | typed source artifact, conversion spec | typed transformed artifact | preserve provenance |
| FIRE | ACTIVATE | approved executable plan, inputs | build, render, simulation result | bounded sandbox |
| LIFE | EVOLVE | evaluation results, expected outcomes | assessment, proposed revision | no self-promotion |

These are capability roles. One task may use several; tools must be discovered and authorized independently.

## Canonical corridor
Human intent -> ATG Semantic IR -> agent identity and mandate references -> AEGIS policy and authority -> execution envelope -> capability ABI -> AGENT-MCP approved adapter -> result and evidence -> receipt -> VERITY/audit -> approved public projection into WORLD.

ATG does not issue credentials, grant execution authority, or publish production state. Installed != loaded != live != authorized. Presentation != authentication != authority.

## Goal A: Construct a district
T00 human mandate + scope + budget (G0) -> T01 AIR repo/design census (G1) -> parallel T02 EARTH spatial draft and T03 WATER schema/asset transforms (G2) -> T04 FIRE isolated build/render/test (G3) -> T05 LIFE evaluation + repair proposals -> T06 independent VERITY assurance (G4) -> T07 explicit human release approval (G5) -> T08 deployment adapter + post-deploy verification (G6).

All task edges reference versioned artifacts and receipts. A failed gate blocks downstream tasks and emits failure evidence. Repairs create a new task revision. Never treat visual progress as execution proof.

## Goal B: Math54 Elemental Lab
Five **science chambers**, distinct from capability classes:
- EARTH: materials, geology, solids and crystal structures.
- WATER: solutions, phase changes, fluid dynamics and chemistry.
- FIRE: thermodynamics, combustion and reaction kinetics.
- AIR: gases, atmosphere and aerodynamics.
- LIFE: biology, biochemistry, DNA and complex systems.

First bounded demonstration: WATER + FIRE, an interactive water/electrolysis and thermodynamics lesson. Chemistry54 is a domain module, not a new authority plane. Scientific models require units, assumptions, uncertainty, conservation checks, solver versions, references and clear labels distinguishing calculated outputs from approximate simulation or artistic visualization. No hazardous real-world experimental instructions are necessary for the MVP.

## Proposed adapter tool surface (not claims of existing MCP tool names)
- AIR: repo.inspect, graph.query, design.read.
- EARTH: spatial.plan, blender.scene_create, asset.generate.
- WATER: scene.transform, asset.convert, schema.validate.
- FIRE: build.execute, render.execute, simulation.run, test.run.
- LIFE: eval.score, drift.compare, improvement.propose.

Tool discovery != authorization. Each invocation requires mandate_ref, actor identity, policy_ref, capability ABI, allowlisted tool, input artifact digest, cost/time/retry ceilings, execution envelope, evidence and receipt. Default deny network and paid APIs. Zero incremental API spend is a target enforced by runtime controls, not guaranteed by a JSON field.

## Digital Mirror
WORLD is the existing public spatial plane. Private control-plane events must be filtered into approved, privacy-safe manifests. Mirror events: goal.accepted, task.queued, task.started, tool.invoked, artifact.created, validation.passed, validation.failed, task.completed, approval.requested, release.approved, deployment.verified, drift.detected. Each event requires schema version, unique ID, district ID, task ID, actor ID, timestamp, ordered sequence, prior/current state, authority reference and verifiable evidence reference. Replay is deterministic and deduplicated; stale, missing or unsigned evidence is visibly flagged. No synthetic telemetry represented as live.

## Ownership
ATG: semantics and schemas. AGENT-MCP: authorized adapters. CREATOR-CORE: shared asset/scene generation contracts. CREATOR: design intent and Foundry assets. CONSTRUCTION: engineering, CI, test and deployment. MATH54: scientific modeling and validation (canonical repo to be located). WORLD: spatial projection only. AEGIS/54T: policy and containment. VERITY: independent review.

## Minimum acceptance criteria
1. Three generated district buildings, deterministic manifest, navigable WORLD scene.
2. One real bounded execution path with receipt and replayable Digital Mirror events.
3. Two educational scientific experiences (Water and Fire) with validated equations and provenance.
4. Static/offline-first fallback; no unapproved spend or external writes.
5. Independent review and explicit human authorization before production publication.

This document is a design contract only. No claims of installed MCP tools, validated simulations, live mirror, or completed deployment.
