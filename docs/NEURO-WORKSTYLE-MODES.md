# NEURO Workstyle Modes

## Status
Recovered canon with partial source rehydration.

## Canonical quartet

| Mode | Core role | Preferred system behavior |
|---|---|---|
| ARCHITECT | Pattern mapper and strategic planner | maps, dependencies, sequencing, tradeoffs, architecture-first |
| SPARK | Creative idea generator | options, branching, novelty, rapid capture, short bursts |
| ANCHOR | Stabilizer for process and QA | checklists, state, consistency, visible progress, fewer switches |
| PHANTOM | Deep-focus researcher/writer/coder | low interruption, bounded autonomy, deep work, concise handoff |

These modes are voluntary workstyle and interface preferences. They are not diagnoses, protected-class proxies, aptitude scores, or employment-selection criteria.

## Relationship to other systems

These modes are independent from:

- `presentation_mode`: MAIN_STREET, BUILDER, DEVELOPER
- `text_verbosity`: LOW, MEDIUM, HIGH
- ATG cognitive coverage functions such as NI_FORESIGHT or TE_EXECUTION
- agent identity
- execution authority
- AEGIS risk decisions
- PAYRAIL settlement routing
