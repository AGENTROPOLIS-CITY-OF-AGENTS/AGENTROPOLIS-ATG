# Withdrawn localization name

The localization proposal formerly named `ATG:LANGUAGE` is superseded by
[ATG:LOCALIZATION](ATG-LOCALIZATION-PROFILE-v0.1.md), version 0.1.0-draft.2.
It is not an alias or replacement for the existing ATG LANGUAGE Atralith native
surface in `ATG-PROFILE-LANGUAGE.md` and `registries/language-surface.yaml`.
Do not implement the former projection or its `publishAllowed` boolean.
